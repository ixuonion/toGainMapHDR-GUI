GainMapHDR 2.1.0 新增“保存到照片图库”，保留现有 Studio 三栏布局和文件夹输出流程。

- 在输出位置选择“照片图库 / Photos Library”，使用 PhotoKit 将转换后的 HEIC 原文件直接添加到图库，不进行二次编码。
- 仅申请 `.addOnly` 权限，提供中英文权限说明、保存状态和失败提示。
- 支持单张、批量及同名输入；取消后停止后续任务，已提交的保存等待系统结果后清理暂存文件，已保存照片保留。
- iCloud Photos 同步由系统处理，应用只报告照片图库保存结果。

系统要求：macOS 27.0 或更高版本，Apple Silicon。下载 ZIP 并解压得到 `GainMapHDR.app`。
应用为 ad-hoc 签名构建，尚未进行 Developer ID 公证。

验证：Swift 6 严格并发构建和自动测试通过（测试运行报告 34 tests / 8 suites；依赖额外样本和开关的集成及性能测试默认跳过）。Release 应用已通过签名及打包权限说明检查。自动测试使用图库替身；真实系统权限弹窗、图库写入及导出原片比对尚未实测，详见仓库中的 `docs/validation/PHOTOS-LIBRARY.md`。

English: Adds Photos Library as an output destination using add-only PhotoKit access. Converted HEIC originals are imported without re-encoding. Includes single/batch saving, cancellation, failure reporting, temporary-file cleanup, and English/Chinese strings while preserving the existing UI layout and folder output. iCloud Photos syncing is managed by the system. Requires macOS 27+ on Apple Silicon; the app is ad-hoc signed and not notarized.
